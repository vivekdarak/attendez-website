# Kitchen & Bathroom Remodeling Campaign Instructions

## Campaign Positioning

This campaign is for kitchen remodeling and bathroom remodeling companies in the US.

The offer should be positioned as:

> Website modernization for kitchen and bathroom remodelers, built to improve trust, speed, lead generation, tracking, SEO, and AI-search visibility.

Do not present this as a generic website design service. The messaging should show that Attendez understands how remodeling customers evaluate contractors online.

## Important Positioning Rule

Do not claim that Attendez has completed kitchen or bathroom remodeling projects unless there is a real portfolio item available.

At the same time, there is no need to disclose that the current portfolio does not include remodeling projects. The campaign should focus on category understanding, website architecture, migration capability, and measurable marketing improvements.

## Core Angle

Many remodeling companies already have a website, often built on WordPress. The campaign should speak to businesses whose current site may be:

- Slow to load
- Difficult to update
- Dependent on plugins
- Weak at showing project proof
- Poorly structured for service-area SEO
- Missing proper conversion tracking
- Not ready for AI search and answer engines

The offer is to migrate or rebuild these websites on a modern stack such as Next.js, React, Node.js, or static HTML where appropriate.

## Preferred Messaging

Use this type of framing:

> If your current WordPress site is slow, difficult to update, or held together by too many plugins, we can rebuild it on a modern stack designed for speed, ownership, SEO, AI visibility, and marketing tracking.

Avoid sounding like WordPress is universally bad. The tone should be professional and practical:

- WordPress can work.
- But many business websites outgrow slow, plugin-heavy WordPress builds.
- Attendez helps businesses move to a faster, cleaner, AI-ready website structure.

## What We Understand About Remodeling Websites

Remodeling customers do not buy only from a beautiful homepage. They need proof, clarity, and confidence before they inquire.

The website should support:

- Before and after project proof
- Project galleries that load quickly
- Clear service pages for kitchen remodeling and bathroom remodeling
- Local service-area pages
- Reviews and trust signals
- Consultation or quote request CTAs
- Financing or budget-related confidence where relevant
- Process clarity
- Fast mobile experience
- Tracking for calls, forms, quote requests, and booked consultations

## What Attendez Brings To The Table

Attendez should emphasize:

- Modern website architecture using Next.js, React, Node.js, or static HTML when appropriate
- Fast loading pages
- Digital marketing ready structure
- Google event and conversion tracking
- Meta conversion tracking
- ChatGPT / AI-search visibility readiness
- SEO, AEO, and GEO friendly content structure
- Easier future changes using AI tools like ChatGPT or Claude
- Clean code ownership through GitHub
- Reduced dependency on agency-controlled website files
- Image performance through optimized hosting and transformation

## Ownership Message

Code ownership should be mentioned, but subtly.

The key message:

> Your website code can live in GitHub, so your business is not locked into an agency-controlled website.

This should not dominate the page, but it should appear in a section about ownership, portability, or long-term control.

## Recommended Landing Page Structure

1. Hero
   - Website modernization for kitchen and bathroom remodelers.
   - Focus on speed, trust, lead generation, and AI-ready architecture.

2. Problem
   - Many remodeling websites look acceptable but are slow, hard to update, poorly tracked, or weak at converting homeowners.

3. What We Understand
   - Homeowners choose based on proof, reviews, project photos, local relevance, process clarity, and confidence.

4. Migration Offer
   - Move from WordPress to a modern React / Next.js website without losing content, SEO value, or brand equity that already works.

5. What We Improve
   - Speed
   - Service pages
   - Project galleries
   - Before and after layouts
   - Forms and call CTAs
   - Google, Meta, and ChatGPT conversion tracking
   - Schema
   - SEO, AEO, and GEO readiness

6. Ownership
   - Website code can be hosted in GitHub.
   - The business can fork, copy, or control the code.
   - The client is not dependent on a final ZIP or RAR file dump from an agency.

7. CTA
   - Request a remodeling website audit.
   - Request a WordPress migration review.
   - Get a website modernization plan.

## Tone Guidelines

The tone should be:

- Professional
- Direct
- Practical
- B2B-focused
- Confident without pretending to have a remodeling portfolio
- Focused on business outcomes, not technical flexing

Avoid:

- Overusing the word AI
- Claiming experience that is not real
- Over-attacking WordPress
- Generic “beautiful website” language
- Long technical explanations in the hero
- Eyebrow elements above section titles
